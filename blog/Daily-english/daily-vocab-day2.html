phrase
window shopping
只逛不买，橱窗购物
Example
"We didn't buy anything today — we were just window shopping to see what's out there."
今天什么都没买——只是随便逛逛看看有什么。
noun
fitting room
试衣间
Example
"Can I use the fitting room? I'd like to try this jacket on before I decide."
我可以用试衣间吗？我想在决定之前先试试这件夹克。
verb
try on
试穿，试戴
Example
"I want to try on a few pairs of jeans before choosing — do you have my size in stock?"
我想先试几条牛仔裤再决定——你们有我的尺码吗？
noun
sale rack
打折区货架，特价区
Example
"I found this dress on the sale rack for only twenty dollars — what a bargain!"
我在特价区发现了这条裙子，只要二十美元——太划算了！
phrase
in stock
有库存，现货
Example
"Sorry, that colour is not in stock right now, but we can order it for you online."
抱歉，那个颜色目前没有现货，但我们可以帮您网上订购。
verb
exchange
换货，换尺码
Example
"I'd like to exchange this shirt for a larger size — I kept the receipt."
我想把这件衬衫换一个大一码的——我保留了收据。
noun
loyalty card
会员卡，积分卡
Example
"Do you have a loyalty card? You get points every time you shop and can redeem them later."
你有会员卡吗？每次消费都可以积分，之后可以兑换。
verb
splurge on
挥霍，奢侈消费
Example
"I decided to splurge on a nice handbag since I've been saving up for months."
我决定买一个好点的手提包犒劳自己，毕竟存了好几个月的钱了。
phrase
good value for money
物超所值，性价比高
Example
"This coat is a bit pricey, but it's really good value for money given the quality."
这件大衣有点贵，但考虑到质量，真的很值。
noun
impulse buy
冲动消费，一时兴起购物
Example
"I didn't plan to get those shoes at all — it was totally an impulse buy at the last minute."
我根本没打算买那双鞋——完全是最后一刻冲动消费了。
